Perimeter

Every instrumented tool call is evaluated before it runs. Actions taken through paths Runwall does not instrument are not mediated — see docs/UNINSTRUMENTED_PATHS.md.

Armed

HALT-class actions stay refused while disarmed. There is no permanent off switch.

Tunnel

Live decision stream. Every route is recorded, including ALLOW — a ledger of refusals alone cannot answer what an agent actually did.

connecting

Approvals

A blocked call waits here. Approving issues a scoped, time-boxed grant keyed to the action's intent, so the agent's retry proceeds without you having to hold a socket open.

Ledger

Hash-chained and tamper-evident — modification is detectable, not prevented. Contains prompts, paths and arguments: treat it as sensitive data.

Policy

Deterministic rules — regex, path comparison, set membership. No rule consults a language model, which is why an agent cannot argue its way past one.
